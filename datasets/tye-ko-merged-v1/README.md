# TYE Korean Correction · merged v1

기존 5시간 자료와 추가 train/eval 묶음 전체를 통합해 다시 분할했습니다. **독립 청취 미검수** 상태입니다. 음성 + 초안 → 전체 전사 교정 규격은 그대로입니다.

| Split | 녹음 | 시간(초) | 화자 | Clean / Single / Multiple |
|---|---:|---:|---:|---|
| train | 472 | 4395.970812 | 63 | 157 / 150 / 165 |
| eval | 409 | 3600.034813 | 20 | 137 / 136 / 136 |
| test | 1750 | 14399.816750 | 32 | 583 / 583 / 584 |

train과 eval은 음성·초안·정답 공개용이며 test 정답은 운영자 전용입니다. 전체 입력 풀은 4,081개·약 9시간 42분입니다. 같은 문장의 다른 화자 녹음을 중복 점수로 계산하지 않으며, 중복·화자 겹침·목표 시간 초과 녹음은 운영자 예비 풀에 보존합니다.

이미 공개된 eval/pilot 정답과 화자는 test에서 제외했습니다. 세 split 사이 화자·세션·동일/근접 문장(SequenceMatcher ≥0.85)·PCM 중복을 허용하지 않습니다. 분할은 ASR 결과나 정답 오류율을 보고 고르지 않았습니다.

원천 전사는 NFC만 적용하고 음성은 원본 PCM을 보존합니다. 희소 명사 치환으로 Clean 0곳 / Single 1곳 / Multiple 2곳을 생성했습니다. train은 기존 초안을 유지하며 eval/test는 같은 생성 규칙으로 길이별 세 발화 묶음에 조건을 다시 배정했습니다.

`source-pool`과 reserved는 학습·개발용이 아닙니다. 새 test의 원본·정답·다른 화자 녹음이 포함되어 있으므로 운영자만 보관합니다. 기존 5시간 버전·추가 ZIP의 점수와 새 점수를 섞지 않습니다.

이전 test의 일부가 새 train으로 이동했습니다. 새 train 정답을 공개하면 이전 test는 종료된 버전의 재현 기록으로만 취급하고 공식 평가에 계속 사용하지 않습니다.
