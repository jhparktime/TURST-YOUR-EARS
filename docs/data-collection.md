# 데이터 수집·구축 기록

현재 리더보드의 데이터는 **`tye-ko-asr-v2`**, 평가 규격은 **`ko-correction-v2`**입니다.
Zeroth Korean의 공개 음성·전사를 확보하고 기존 자료와 추가 자료를 통합한 뒤,
동일 녹음에 실제 ASR 초안을 붙여 한국어 전사 교정 과제로 구성했습니다.
참가 모델의 입력은 `id, audio, draft`, 출력은 `id, prediction`입니다.

## 1. 어디서 확보했나

| 항목 | 기록 |
|---|---|
| 원천 코퍼스 | [Zeroth Korean / OpenSLR SLR40](https://www.openslr.org/40/) |
| 사용한 배포본 | [kresnik/zeroth_korean 고정 버전](https://huggingface.co/datasets/kresnik/zeroth_korean/tree/1fe937899f828af822293d05e086200946088bdf) |
| 원천 revision | `1fe937899f828af822293d05e086200946088bdf` |
| 이용 조건 | CC BY 4.0. 배포물 NOTICE에 원천·저작자·가공 내역을 표기 |
| 자료 형태 | 한국어 낭독 음성과 배포 전사. 원천 화자·세션 식별자로 분할 검사 |
| 확보·확인 코드 | [zeroth_source.py](../scripts/zeroth_source.py): 고정 Parquet 파일의 크기와 SHA-256 검사, 음성 복호화 및 인덱싱 |

직접 녹음하거나 TTS로 음성을 생성하지 않았습니다. 원천의 FLAC을 WAV로 내보내면서
16 kHz·모노·PCM16 샘플을 보존했습니다. 속도 변경, 반복, 인위적 무음 추가로 분량을 늘리지 않았으며
재생 시간에는 원래 녹음에 포함된 무음이 들어갑니다. 정답은 원천 `text`에 Unicode NFC만 적용했습니다.
숫자·단어를 ASR 결과에 맞춰 바꾸지 않았습니다.

## 2. 기존 자료와 추가 자료를 어떻게 합쳤나

동일한 Zeroth Korean 원천을 이용한 **기존 5시간 묶음 2,079개 + 추가 Train/Eval 묶음 2,002개**를
통합했습니다. 추가 파일을 새로운 코퍼스로 세거나 동일 문장의 다른 화자 녹음을 독립적인 평가 문장으로
분산하지 않도록 원천 ID, 전사, 화자·세션, WAV/PCM 해시를 대조했습니다.

| 통합 단계 | 녹음 수 | 처리 |
|---|---:|---|
| 확보한 통합 풀 | 4,081 | 34,927.3378125초, 원천 화자 ID 115개 |
| 실험에 사용하는 분할 | 2,631 | Train 472 + Eval 409 + Test 1,750 |
| 예비 풀 | 1,450 | 평가 문장과 동일 1,281 / 근접 문장 1 / 평가 화자의 대체 녹음·목표 시간 초과 168 |

원본 4,081개와 출처 대응표는 운영자 자료에 보존했습니다. 예비 풀은 평가 발화의 정답이나 대체 녹음을
포함할 수 있어 학습·프롬프트 튜닝에 사용하지 않습니다.
이 수치는 [통합 메타데이터](../datasets/tye-ko-merged-v1/metadata.json)에 기록되어 있습니다.
초기 FLEURS·pilot160 실험은 과거 버전으로 관리하며 현재 데이터의 별도 원천으로 합산하지 않습니다.

## 3. 어떻게 Train / Eval / Test를 나눴나

분할 seed는 `20261016`입니다. 목표는 **평가 분량 5시간 = 공개 Eval 1시간 + 비공개 Test 4시간**이며,
Train은 별도로 확보한 약 1시간 13분입니다.

| 분할 | 녹음 수 | 실제 시간(초) | 원천 화자 ID 수 | 용도·정답 공개 |
|---|---:|---:|---:|---|
| Train | 472 | 4,395.9708125 | 63 | 학습 / 공개 |
| Eval | 409 | 3,600.0348125 | 20 | 개발·웹 채점 / 공개 |
| Test | 1,750 | 14,399.81675 | 32 | 운영자 최종 평가 / 비공개 |

기존 공개 Eval의 화자 그룹을 Eval 후보로 유지하고, 공개된 Eval 및 추가 정답 포함 Train의 화자는
새 Test에서 제외했습니다. 이미 노출된 정답과 동일하거나 유사한 Test 후보 문장도 제외했습니다.
Eval/Test와 화자·전사가 겹치지 않는 나머지 녹음을 Train에 배정했습니다.
목표 시간을 맞추려고 발화를 자르지 않아 초 단위 차이가 있습니다.

통합 단계에서 분할 간 화자·세션·정규화한 동일 문장·PCM 중복과
`SequenceMatcher` 유사도 0.85 이상 문장을 검사했습니다.
v2는 이 녹음·정답·분할을 그대로 유지하고, 화자·세션·동일 문장·오디오 겹침을 다시 검사했습니다.
근접 문장 검사는 통합 버전에서 수행한 결과를 계승합니다.
화자 수는 원천 ID 기준이며 개인 신원을 별도로 확인한 수치는 아닙니다.

선정·검사 코드는 [merge_correction_datasets.py](../scripts/merge_correction_datasets.py),
[validate_merged_dataset.py](../scripts/validate_merged_dataset.py)에 있습니다.

## 4. 실제 ASR 초안을 어떻게 만들었나

원본 음성만 입력한 두 인식기의 출력을 초안으로 사용합니다. 정답을 프롬프트에 넣거나
전사의 몇 단어를 직접 바꾸는 방식은 현재 v2 초안 생성에 사용하지 않습니다.

| 생성기 | 고정 모델 revision | 설정 |
|---|---|---|
| Whisper large-v3-turbo | `mlx-community/whisper-large-v3-turbo@a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb` | 한국어, temperature 0, 이전 발화 문맥 재사용 없음 |
| Qwen2.5-Omni-3B | `Qwen/Qwen2.5-Omni-3B@f75b40e3da2003cdd6e1829b1f420ca70797c34e` | audio-only, seed 0, greedy, 최대 새 토큰 512 |

발화마다 초안은 하나입니다. 각 분할에서 `SHA256(seed:split:id)` 순으로 정렬하고 생성기를 번갈아
배정했습니다. 배정 seed는 `tye-real-asr-v2-assignment-20261016`입니다.
이 과정은 정답 전사·오류율을 읽지 않으며, 더 잘하거나 더 못한 모델 출력을 골라 쓰지 않습니다.

| 분할 | Whisper 초안 | Qwen 초안 | 정규화 기준으로 원래 맞은 초안 |
|---|---:|---:|---:|
| Train | 236 | 236 | 165 |
| Eval | 205 | 204 | 131 |
| Test | 875 | 875 | 626 |

맞은 초안도 포함하며 Clean 비율을 인위적으로 맞추지 않았습니다. 실제 출력에 NFC만 적용하고,
길이 한도에 도달한 출력도 보존했습니다. 기존 추론 결과는 입력 WAV 해시·모델 버전·설정이
일치할 때 재사용했고 부족한 Train 초안을 같은 조건으로 생성했습니다.
배정표 SHA-256은 `a7dbd2d68fc8560a9b9ebaa2cd69d4e8860f3f481d310fe36a045a2ce694b330`입니다.

## 5. 무엇을 검사하고 배포했나

자동 검증은 활성 녹음 2,631개 전체의 복호화·재생 시간·체크섬, 원천 전사 보존,
초안과 실제 추론 출력의 일치, 생성기 배정 및 분할 간 겹침을 확인했습니다.
Copy 제출은 변경·훼손이 0이고, 정답 제출은 CER가 0인지 검사했습니다.
Python과 브라우저 평가기의 공개 Eval 전체 지표 일치도 확인했습니다.

- **참가자 묶음:** Train/Eval 음성·초안·정답, 출처·라이선스, 파일 체크섬과 실행 안내.
- **운영자 자료:** Test 정답·개별 출력, 원천 대응표, 예비 풀과 검수 기록.
- **Test 입력을 별도로 배포할 때:** 음성·초안만 포함하고 정답·오류 유형·대응표는 제외.

[자동 검증 보고서](measurements/real-asr-v2-validation.json) ·
[검증 코드](../scripts/validate_real_asr_v2.py) ·
[배포 코드](../scripts/package_real_asr_v2.py) ·
[참가자 ZIP·SHA-256](https://github.com/jhparktime/TURST-YOUR-EARS/releases/tag/dataset-ko-asr-v2)

정답은 원천 배포 전사를 기준으로 하며, 운영자가 전사 확인을 완료했습니다. [전사 확인 기록](reference-confirmation.md)을 함께 제공합니다.
자동 검사는 파일·분할·출력 일치의 검사이며 모든 원천 전사의 음향적 정확성을 보증하지 않습니다.
정답 이의는 발화 ID와 근거를 [Issues](https://github.com/jhparktime/TURST-YOUR-EARS/issues)에 남기고,
수정 시 데이터 버전과 영향받는 점수를 함께 갱신합니다.

## 6. 버전 이력과 해석 범위

초기 v1은 정답의 명사를 비슷한 실제 단어로 치환한 합성 초안을 사용했습니다.
현재 v2에서는 그 초안을 실제 ASR 출력으로 교체했습니다. 음성·정답·분할은 유지했습니다.
기존 Eval/Test 풀에는 v1에서 두 곳의 합성 치환 후보를 확보할 수 있는 문장으로 선정된 이력이 있어,
v2가 모든 한국어 발화를 대표하는 무작위 표본이라고 해석하지 않습니다.
v2 생성기 배정에 오류율을 사용하지 않았다는 설명은 이 과거 선정 이력과 구분합니다.

v1 Test 집계는 v2 설계 전에 확인되어 있었습니다. 새롭게 완전히 블라인드로 만든 시험이라고
주장하지 않으며 [설계 동결 기록](measurements/real-asr-v2-design-provenance.json)을 제공합니다.
공개 원천의 모델 사전학습 포함 가능성과 원문 검색 가능성도 남아 있습니다.
낭독 음성이므로 자발적 대화·모든 도메인의 성능으로 일반화하지 않습니다.

음질 손상 보조 트랙은 같은 공개 Eval 409개의 원본·5 dB 합성 잡음·20% 패킷 손실 변형입니다.
총 1,227개 파일이어도 독립 녹음은 409개이며, 본 데이터의 분량에 세 번 합산하지 않습니다.
[보조 트랙 구축 기록](public-eval-stress-probe.md)에서 가공 강도·seed·해석 범위를 확인할 수 있습니다.

실험 단위·지표가 다른 v1과 v2 점수는 같은 순위에 섞지 않습니다.
자세한 평가 규칙은 [v2 규격](real-asr-v2.md), 과거 통합 기록은 [통합·분할 문서](merged-dataset.md)에 있습니다.
