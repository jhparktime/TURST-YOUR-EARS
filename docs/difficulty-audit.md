# 난이도 점검: merged-v1

현재 자료는 한국어 음성과 합성 오류 초안을 함께 주는 전사 교정용 파일럿이다.
실제 ASR 오류를 수집한 벤치마크나, 문맥만으로 풀 수 없음을 검증한 자료로 소개해서는 안 된다.

## 확인한 사실

생성기 `build_five_hour_dataset.py`의 `variants_for`는 원문 명사에 대해
자모 성분이 가까운 실제 명사를 선택한다. 조사 결합 형태를 보존하고 일부 동음어를 제외하지만,
치환 후 문장의 의미적 자연스러움이나 음성이 정답 판별에 꼭 필요한지는 검사하지 않는다.

공개 eval 409문장의 평균 정규화 길이는 44.115자이다. 오류 개수는
0곳 137문장, 1곳 136문장, 2곳 136문장이다. 전체 치환 408건은 모두 같은 글자 수의 단어로
바뀌며, 정답 단어와의 음절 편집 거리는 1인 경우 341건(83.58%), 2인 경우 67건이다.
이는 공개 eval의 집계이며, 문장 예시를 고르기 위해 private test를 살펴보지 않았다.

고정 Whisper audio-only는 test의 주입 오류 1,751곳 중 1,696곳(96.86%)을 복원했지만,
정상 구간 훼손률은 5.45%이고 Macro CER는 5.34%이다. Copy의 Macro CER는 2.72%이다.
복원률은 주입한 오류 구간의 정확 일치율이며 문장 전체 정확도와 다르다.
Whisper는 초안을 받지 않았으므로 이 결과만으로 audio+draft 교정 성능을 판정할 수 없다.

## 현재 판단과 남은 검증

Qwen2.5-Omni-3B Text-only는 공개 eval 409개 전체의 추론을 완료했다. Macro CER는
8.4616%, 주입 구간 복원률은 37/408(9.0686%), 정상 구간 훼손률은
958/17,213(5.5656%), Clean 변경률은 61/137(44.5255%)이다.
같은 eval의 Copy Macro CER는 2.6263%이다. 진행 중인 전체 체크포인트에서
eval ID 409개가 정확히 일치하는지와 입력·초안 해시를 확인한 뒤 별도 사본을 채점했다.
부분 문장 집합을 전체 결과로 보고한 수치가 아니다.
[집계 지표와 고정 실행 설정](measurements/qwen-text-only-eval.json)을 함께 보관한다.
이후 Text-only의 eval/test 2,159개 전체 추론을 완료하고, 고정 입력과 출력의 ID·해시 일치를
확인한 뒤 채점했다. Test 1,750개의 Macro CER는 10.6928%, 복원률은 145/1,751(8.2810%),
정상 구간 훼손률은 5,184/70,783(7.3238%), Clean 변경률은 286/583(49.0566%)이다.
512 토큰 한도에 도달한 Test 출력 1개도 실제 출력 그대로 포함했다. 생성 한도를 늘리거나
초안으로 대체하지 않았다. [완료된 입력 조건의 집계·실행 증빙](measurements/qwen-text-only-completed.json)을
확인한다. Audio+draft와 Audio-only도 이후 전체 실험을 완료했다.

Audio+draft도 공개 eval 409개 전체 추론을 완료했다. 같은 Qwen의 Macro CER는
Text-only 8.4616%에서 Audio+draft 4.7073%로 낮아졌다. Audio+draft의 복원률은
272/408(66.6667%), 정상 구간 훼손률은 640/17,213(3.7181%), Clean 변경률은
42/137(30.6569%)다. 다만 Copy 2.6263%보다 CER가 높으므로, 이 설정의 교정이 초안
보존보다 낫다고 할 수 없다. [공개 eval 집계와 고정 설정](measurements/qwen-audio-draft-eval.json)을
보관한다. 이후 Audio+draft의 eval/test 2,159개 전체 추론을 완료했다. Test Macro CER는
4.3833%, 복원률은 1,181/1,751(67.4472%), 정상 구간 훼손률은
2,106/70,783(2.9753%), Clean 변경률은 151/583(25.9005%)이다.
고정 생성 한도 512토큰에 도달한 Test 출력 1개도 그대로 채점했다.
[전체 입력·출력 검증과 집계](measurements/qwen-audio-draft-completed.json)를 보관한다.
메모리 정리를 추가해 재개한 시점 이전의 1,183개 예측과 완료된 Text-only 실행 기록이
변하지 않았음을 확인했다. 모델·프롬프트·생성 한도·후처리·정답은 바꾸지 않았다.

같은 Qwen의 Test에서도 Text-only 10.6928%에서 Audio+draft 4.3833%로 CER가 낮아졌다.
그러나 Copy 2.7211%보다 높다. Multiple 조건은 초안 CER 5.4982%에서 4.3434%로
개선됐지만, Clean 3.6926%·Single 5.1138%의 오류 때문에 전체 Macro CER는 악화됐다.
오류 복원과 정상 부분 보존을 함께 봐야 한다는 결과이며, 데이터가 충분히 어렵다는 증거는 아니다.
같은 모델 Audio-only의 공개 eval도 이후 완료됐다. 아래는 동일한 공개 409개에서 비교한 결과다.

| 입력 조건 | Macro CER ↓ | 오류 복원률 ↑ | 정상 구간 훼손률 ↓ |
|---|---:|---:|---:|
| Copy draft | 2.6263% | 0% | 0% |
| Qwen Text-only | 8.4616% | 9.0686% | 5.5656% |
| Qwen Audio-only | 13.9612% | 93.3824% | 10.1842% |
| Qwen Audio+draft | 4.7073% | 66.6667% | 3.7181% |

Audio-only는 주입 오류 408곳 중 381곳을 복원했지만 정상 구간 17,213자 중 1,753자를
훼손했고, 정상 초안 137개 중 98개(71.5328%)와 다른 결과를 냈다.
512토큰 한도에 도달한 공개 eval 출력 1개도 실제 출력 그대로 포함했다.
[전체 공개 eval 집계·고정 설정·생성 진단](measurements/qwen-audio-only-eval.json)을 보관한다.
공개 개발셋에서는 초안과 음성을 함께 주는 것이 각 입력만 제공하는 것보다 CER가 낮았다.
이 결과는 해당 모델·설정에서의 관찰이며, 교정이 Copy보다 낫거나 합성 과제가 충분히
어렵다는 뜻은 아니다.

Audio-only의 Test 1,750개도 모두 완료했다. Macro CER는 10.4046%, 오류 복원률은
1,609/1,751(91.8903%), 정상 구간 훼손률은 6,389/70,783(9.0262%), Clean 변경률은
397/583(68.0961%)이다. Test에서 생성 한도에 도달한 출력 1개도 포함했다.
[전체 세 입력 비교 검증](measurements/qwen-audio-only-completed.json)에서 6,477개 예측의
입력·출력과 여섯 Qwen 측정값이 고정 실행 기록에 일치하는지 확인했다.

| Test 입력 조건 | Macro CER ↓ | 오류 복원률 ↑ | 정상 구간 훼손률 ↓ |
|---|---:|---:|---:|
| Copy draft | 2.7211% | 0% | 0% |
| Qwen Text-only | 10.6928% | 8.2810% | 7.3238% |
| Qwen Audio-only | 10.4046% | 91.8903% | 9.0262% |
| Qwen Audio+draft | 4.3833% | 67.4472% | 2.9753% |

두 입력을 함께 제공한 결과는 eval/test 모두 각 입력만 제공한 결과보다 CER가 낮았다.
하지만 두 분할 모두 Copy보다 CER가 높다. 따라서 이 고정 모델·설정에서는 입력 결합의
이득이 관찰되지만, 교정이 초안을 그대로 유지하는 것보다 유리하다고 결론 내릴 수 없다.

오류 종류가 좁고 초안 오류율이 낮다는 한계는 확인했다. 주입 오류를 음성으로 복원하는
하위 과제는 Whisper에서 높은 복원률을 보인다. 반면 고정 Qwen의 Text-only는 공개 eval에서
낮은 복원률과 불필요한 수정이 관찰됐다. 이 한 모델의 실패를 모든 텍스트 모델의 한계로
일반화할 수 없으며, Whisper와 Qwen의 차이는 모델과 입력이 함께 달라 음성 효과만을
분리하지 못한다. 같은 Qwen의 eval/test에서는 음성과 초안의 결합 시 CER가 낮아졌지만,
이 결과를 다른 모델이나 실제 ASR 오류 분포에 대한 일반화로 해석하지 않는다.
독립 청취를 통한 원문 검수도 아직 하지 않았다.

리더보드는 Macro CER와 함께 조건별 CER, 오류 복원률, 정상 구간 훼손률,
Clean 변경률을 표시한다. 복사 기준점은 반드시 유지한다. 측정한 결과에 맞춰
기존 정답이나 정규화 규칙을 바꾸지 않는다.

## 공개 eval의 단순 규칙 진단

후속 점검에서 기존 Whisper 출력의 같은 길이 한글 치환만 선별하는 규칙을 공개 eval에 적용했다.
모든 409개를 채점했고, 음절 변화/자모 거리 한도 0/0·1/1·1/2·2/2·2/3의 결과를 전부 보관했다.
2/2 조합의 Macro CER는 1.7106%로 Copy의 2.6263%보다 낮았고 복원률은 286/408(70.0980%)였다.
정상 구간 훼손률은 172/17,213(0.9992%), Clean 변경률은 42/137(30.6569%)이다.
[재현 코드·전체 후보·공개 예측과 독립성 감사](measurements/selective-public-eval/README.md)를 확인한다.

생성 규칙을 아는 필터가 유리하다는 증거이며, 한 Text-only 모델의 실패를 곧바로
충분한 난도의 증거로 삼으면 안 된다. 이는 공개 개발셋 진단이고 비공개 성능이나 독창성의 증거가 아니다.
이번 진단은 비공개 Test 파일을 열지 않았고 후보 비교에는 공개 eval만 사용했다. 다만 기존 Whisper
Test 집계를 이미 확인·공개한 이후의 분석이므로, 완전히 블라인드인 설계라고 주장하지 않는다.
이 필터의 비공개 성능은 측정하지 않았고 기존 Test도 바꾸지 않았다.

## 다음 버전 설계안 (아직 생성하지 않음)

- 정상 문장: 이미 맞는 초안을 보존하는지 측정한다.
- 통제된 합성 치환: 현재 조건을 유지해 이전 실험과 비교 가능한 진단 자료로 쓴다.
- 문맥상 자연스러운 혼동: 발음이 가깝고 두 후보 모두 문맥에 들어갈 수 있는 명사·개체·수량을
  후보로 만들고, 사람의 독립 검수로 정답의 청각적 구분 가능성을 확인한다.
- 실제 ASR 오류: 개발용 음성에서 고정된 복수 ASR 시스템으로 초안을 생성하고,
  인식기별 난이도와 오류 유형을 분석한다. 특정 평가 모델이 틀린 샘플만 골라 test를 만들지 않는다.

유형·분할·검수·집계 규칙은 공개 개발 자료에서 정한 다음 새 private 평가에 적용한다.
추가 시간 왜곡이나 잡음은 별도 조건으로 두어 음성 명료도와 초안 오류의 영향을 구분한다.
완전 동음어처럼 음성만으로도 구별할 수 없는 표기는 정답 판별 규칙 없이 강제하지 않는다.
현재 test를 점수에 따라 고쳐 덮어쓰지 않으며, 버전을 바꿀 때 기존 점수와 분리한다.
