# Trust Your Ears: 실제 ASR 초안을 이용한 v2

상태: 구축 중인 새 버전. 기존 `tye-ko-merged-v1`의 결과·정답·웹 채점은 유지한다.
새 데이터는 `tye-ko-asr-v2`, 평가기는 `ko-correction-v2`로 분리한다.
이 문서의 배정·집계 규칙은 v2 Test의 오류 분포를 분석하기 전에 정한다.
v1의 모델별 Test 집계는 이미 확인한 상태이므로 완전히 블라인드로 설계한 새 시험이라고 주장하지 않는다.

## 과제와 데이터

입력은 한국어 음성과 실제 인식기가 출력한 전사 초안이다. 출력은 실제 발화에 맞게 교정한 전체 전사다.
학습 472개·약 1시간 13분, 공개 Eval 409개·1시간, 비공개 Test 1,750개·4시간의
기존 화자·세션·문장·PCM 분리를 그대로 유지한다. 평가 모델이 틀린 녹음만 고르지 않는다.

고정된 두 초안 생성기는 Whisper large-v3-turbo와 Qwen2.5-Omni-3B의 음성 단독 조건이다.
각 split에서 `SHA256(seed:split:id)` 순으로 정렬한 뒤 두 생성기를 번갈아 배정한다.
따라서 Train 236/236개, Eval 205/204개, Test 875/875개다. 발화당 초안은 하나다.
두 인식기의 점수를 본 뒤 좋은/나쁜 출력을 고르는 과정은 없다. 소수 빈 출력·길이 제한 출력도 보존한다.
배정표는 정답 텍스트를 읽지 않는 `scripts.prepare_real_asr_v2`로 생성하고 해시로 잠근다.

기존 음성 단독 실행은 정확한 입력 WAV 해시·모델 버전·출력 기록이 일치할 때 재사용한다.
빠진 학습용 초안은 같은 설정으로 새로 생성한다. 초안에 적용하는 처리는 NFC 합성뿐이다.
원천 음성, 원천 정답과 수치 표기는 바꾸지 않는다. 실제로 맞은 초안도 자연 발생 비율대로 포함한다.
CC-BY-4.0 원천 고지와 고정 출처 버전을 포함한다.

## 평가 규칙

주 지표는 **Micro CER**: 전체 발화의 치환·삭제·삽입 수 합계를 전체 정답 글자 수로 나눈다.
Macro CER는 **발화별 CER의 평균**이다. 합성 v1의 세 조건별 CER 평균과 다른 정의이므로
v1·v2 점수를 같은 순위에서 비교하지 않는다. 추가 복합 가중 점수는 만들지 않는다.

한국어 정규화는 v1과 같게 NFC·소문자 변환·공백 제외·정해진 문장부호 제외를 적용한다.
숫자 사이 소수점은 유지한다. `3시`와 `세 시`는 자동으로 동치 처리하지 않는다.
숫자/영문 표기 차이가 오류에 포함될 수 있음을 명시하고 검수 목록에서 표시한다.
WER는 공백 단위 어절에 같은 정규화를 적용한 보조 지표다. CER와 함께 제공한다.

각 발화를 정답→초안의 결정적 Levenshtein 정렬로 분류한다. 동률 우선순위는
대각선(일치/치환), 삭제, 삽입이다. 조건은 Clean, 치환만, 삭제만, 삽입만, 혼합이다.
조건별·초안 생성기별 CER, 원래 초안 대비 CER 개선폭과 아래 진단 지표를 공개한다.

- 오류 슬롯 복원률: 원래 틀린 문자/삽입 위치 중 결과가 정답으로 돌아온 비율.
- 교정 정밀도: 결과가 바뀐 슬롯 중 올바르게 복원된 슬롯의 비율. 잘못 바꾼 오류도 분모에 포함한다.
- 교정 F1: `2 × 복원 슬롯 수 / (바뀐 슬롯 수 + 원래 오류 슬롯 수)`.
- 정상 문자 훼손률: 초안에서 맞았던 정답 문자 위치 중 결과에서 틀린 비율.
- 불필요 삽입률: 초안에서 비어 있던 삽입 위치 중 결과가 문자를 추가한 비율.
- Clean 변경률: 정규화 기준으로 원래 맞은 초안을 틀리게 바꾼 발화 비율.

길이 L의 정답에 문자 슬롯 L개와 삽입 위치 L+1개를 분리한다. 긴 삽입 문자열은 슬롯 지표에서
한 위치로 세고, CER에서는 실제 삽입 문자 수대로 센다. 분모 0인 비율은 N/A다.
반복 문자열에는 정렬 모호성이 남으므로 슬롯 지표는 음향적 정당성의 증거로 사용하지 않는다.
Python과 브라우저가 동일한 입력에서 같은 수치를 반환하는지 검증한다.

## 비교 실험의 독립성

Copy는 배포 초안 그대로다. Whisper·Qwen Audio-only는 초안 없이 음성만 사용한다.
Text-only·Audio+draft는 **새 실제 ASR 초안**으로 다시 실행해야 한다. v1의 교정 출력을 재사용하지 않는다.
Qwen의 모델·프롬프트·greedy·512토큰 한도를 고정하고 빈/길이 제한 출력도 그대로 평가한다.

초안 생성기와 같은 인식기를 Audio-only 기준점으로 쓰면 그 생성기 부분집합에서는 Copy와 같다.
이를 독립적인 교정 성공으로 해석하지 않는다. 전체 결과와 함께 두 생성기별 결과를 반드시 표시한다.
현재 두 생성기 외 인식기로의 일반화나 미관측 생성기 성능은 검증하지 않았다.
기존 모델들의 사전학습에 공개 원천 자료가 포함됐을 가능성도 배제할 수 없다.

## 검수와 공개

오류 분포·해시·분할 검사는 자동화할 수 있지만, 원천 전사 정확성과 음성의 판별 가능성은 사람이 확인해야 한다.
검수자는 먼저 음성만 듣고 들린 내용을 기록한 뒤 원천 전사와 ASR 초안을 확인한다.
원천 전사 오류·숫자 표기 차이·불명료 발화·실제 인식 오류·정상 초안을 구분한다.
모든 발화를 검수 목록에 넣고, 우선 검수 묶음은 공개 Eval에서 생성기·오류 유형별로 고정 seed로 뽑는다.
우선 검수 순서는 정할 수 있지만 그 결과로 특정 모델이 맞히기 쉬운/어려운 Test만 남기지 않는다.

사람 검수 전 산출물은 **미검수 후보/프리릴리스**로 표시한다. 현실적인 ASR 오류를 포함한다는 사실이
원천 정답의 정확성, 의미적 모호성 해소, 충분한 난도 또는 독창성까지 보장하지는 않는다.
Test 정답·개별 예측·검수표·원천 대응표는 운영자 보관이다. 공개에는 Train/Eval 입력·정답과
집계 결과만 포함하고, Test 입력 배포 묶음에도 정답·오류 유형·검수표를 넣지 않는다.
