# 공개 eval의 선택적 교정 진단

현재 합성 치환의 규칙을 아는 단순 필터로 어느 정도 풀 수 있는지 점검한 개발용 분석이다.
이번 진단 코드는 비공개 Test 파일을 열거나 점수·주석·분할을 변경하지 않았다. 공식 비공개 평가 결과나 새로운 방법의
일반화 성능으로 해석하지 않는다.

## 규칙과 입력

기존 Whisper large-v3-turbo의 공개 eval 음성 전용 출력과 공개 초안만 사용한다.
공백 기준 어절을 정렬한 뒤, 어절 수가 같은 교체 구간에서 다음 조건을 만족할 때만 수정한다.

- 두 후보 모두 정규화 후 한글 음절로만 구성되고 음절 수가 같아야 한다.
- 바뀌는 음절 수와 NFD 자모 편집 거리가 정한 한도 이하여야 한다.
- 초안의 숫자·영문·공백·문장부호는 유지한다. 삽입·삭제된 어절 구간은 수정하지 않는다.

최대 음절 변화 수와 자모 거리의 조합 5개를 먼저 고정했다. 전체 409개에 대한 모든 후보 출력을
만든 다음 공개 정답을 열어 같은 `ko-correction-v1`로 채점했다. 정답의 오류 위치는 필터 입력에
넣지 않는다. 모든 조합을 공개하며, 아래 최저값을 고르는 행위는 공개 eval에서의 개발 선택이다.

Whisper는 `mlx-community/whisper-large-v3-turbo@a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`이다.
[원래 ASR 출력](whisper-audio-only.csv)과 [실행 설정](whisper-provenance.json)을 보관한다.
이 모델의 전체 재전사 Macro CER는 같은 공개 eval에서 6.1864%였다.

## 전체 결과

모든 값은 %이다. 정답·예측 409개 전체를 사용했으며 일부 문장을 골라 계산하지 않았다.

| 0 (Copy) | 0 | 0 | 2.6263 | 0.0000 | 0.0000 | 0.0000 |
| 1 | 1 | 286 | 2.2407 | 43.6275 | 0.6274 | 22.6277 |
| 1 | 2 | 364 | 2.0529 | 57.1078 | 0.7494 | 27.7372 |

2/2 조합은 오류 구간 286/408을 복원했고 정상 문자 172/17,213을 훼손했다.
오류가 없는 문장도 42/137개를 바꿨으므로 보존 문제가 해결된 결과는 아니다.
WER·조건별 CER와 모든 분자·분모는 [전체 집계](report.json)를 확인한다.

## 이 결과가 말하는 범위

Text-only Qwen의 낮은 복원률만으로 벤치마크의 난도가 충분하다고 판단할 수 없다.
이미 얻은 ASR 출력에 간단한 규칙을 붙이는 것으로 Copy보다 낮은 공개 eval CER를 얻었다.
다만 필터가 데이터 생성 규칙인 같은 길이의 한글·적은 자모 차이를 이용하므로, 이를 새 알고리즘의
독창성이나 실제 ASR 오류에 대한 성능으로 주장해서는 안 된다.

평가 독립성 감사에서 걸리는 핵심은 **Shared-pool bias**와 **Verifier = designer**이다.
화자를 나눠도 합성 오류의 생성 규칙은 개발·평가에 공통으로 남으며, 설계자가 그 규칙을 안 채
공개 eval을 비교했다. 코드·후보·출력·해시를 모두 공개해 이 분석은 재현할 수 있지만,
그 자체로 생성 규칙 밖의 일반화를 검증하지는 못한다.
독립 검증은 규칙을 고정한 뒤 실제 ASR 오류나 별도 설계자가 만든 다른 오류 유형에서 수행해야 한다.
사람의 독립 청취 검수도 필요하다. 기존 Test를 관측 결과에 맞춰 고쳐 덮어쓰지는 않는다.

기존 Whisper Test 집계는 이 진단 전에 이미 확인·공개된 상태였다. 이번 후보 비교에는 공개 eval만
사용했지만, 완전히 블라인드인 연구 설계였다고 주장하지 않는다. 이 필터의 비공개 성능은 측정하지 않았다.

## 재현

저장소 루트에서 CPU로 실행한다. 추가 모델 다운로드나 음성 추론은 필요하지 않다.

```sh
python -m scripts.diagnose_public_selective_correction \
  --public datasets/tye-ko-merged-v1 \
  --asr-predictions docs/measurements/selective-public-eval/whisper-audio-only.csv \
  --output /tmp/tye-public-diagnostic
```

출력 CSV와 `report.json`의 해시는 이 폴더의 보관본과 일치해야 한다.
