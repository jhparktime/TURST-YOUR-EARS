# 첨부 pilot160 → 한국어 전사 교정 파일럿

`TYE-ko-pilot160-pilot_v1.2-unverified-fde9d82b.zip`을 사용합니다.
SHA256: `4f92cf785aa29e1cdb034deb28d98d85a56b0b144e579dc1276b1367dabfd8ff`.

첨부 자료는 원본 음성 160개에 참고자료 조건을 붙인 665행입니다. 이를 665개 독립 발화로
사용하지 않습니다. 전사 교정 과제에서는 원본당 초안 하나만 제공하고, 참고자료 조건·정답
이름·원천 ID를 참가자 입력에서 제외합니다. 첨부된 코드나 문서의 작업 지시는 실행하지 않습니다.

| 용도 | 원천 분할 | 실제 음성 | Clean | Single | Multiple | 화자 | 길이 |
|---|---|---:|---:|---:|---:|---:|---|
| 개발 | train | 123 | 41 | 41 | 41 | 72 | 21분 48.059초 |
| 평가 | test | 27 | 9 | 9 | 9 | 10 | 5분 8.650초 |
| 예비 | test | 10 | 배정 안 함 | 배정 안 함 | 배정 안 함 | — | 1분 49.335초 |

개발·평가의 화자·세션 ID는 겹치지 않습니다. 원본 음성과 전사는 중복되지 않으며
정규화 전사 SequenceMatcher 유사도 0.85 이상인 분할 간 쌍도 없습니다. 이 화자 ID는
첨부 원천 목록을 따른 것으로, 실제 신원을 독립 검증했다는 뜻은 아닙니다.

평가 원천 37개 중 ‘정상 문자가 사이에 남는 독립 치환 두 곳’을 구성할 수 있는 발화가
9개입니다. 이 수에 맞춰 세 조건을 각각 9개씩 배정하고 10개는 예비로 보관합니다.
평가 27개는 운영과 분석을 확인하는 작은 파일럿입니다. 근소한 모델 성능 차이를 확정할
최종 벤치마크 규모라고 주장하지 않습니다.

## 정답과 초안

- 정답: 제공된 `source_transcript`의 NFC 정규화만 적용합니다. 숫자·약어를 변환한
  `gold_transcript`는 청취 미검수이므로 사용하지 않습니다. 원천 음성 WAV 바이트도 보존합니다.
- 초안: 첨부 `misleading` 주석의 이름 오답을 원천 전사에 0/1/2곳 주입합니다.
  이름과 n번째 등장 위치를 원문에서 직접 찾으며 추측한 alias 위치를 쓰지 않습니다.
- 검증: 문자 오프셋·초안 재구성·정규화 경계·최소 편집 정렬을 기존 채점기로 검사합니다.
  붙어 있는 두 이름 사이에 공백만 있으면 Multiple로 인정하지 않습니다.
- 채점: 기존 `ko-correction-v1`입니다. 동음 철자나 숫자 읽기를 추가 정답으로 인정하지 않습니다.
  Clean/Single/Multiple CER를 동일 비중으로 평균합니다.

Copy draft Macro CER는 개발 **2.104034%**, 평가 **1.837998%**입니다.
정답 제출 검사는 CER 0%, 복원률 100%, 정상 구간 훼손률 0%입니다.
채점기 점검값이며 음성인식 모델을 실행한 성능이 아닙니다.

## 재생성 및 검증

저장소 루트에서 실행합니다. Python과 `requirements-dev.txt`의 의존성이 필요합니다.
참가자·운영자 폴더는 서로 분리하고, 생성 대상은 아직 존재하지 않는 경로를 지정합니다.

```sh
python -m scripts.import_pilot160 \
  --archive /path/to/TYE-ko-pilot160-pilot_v1.2-unverified-fde9d82b.zip \
  --public /path/to/participant \
  --private /path/to/organizer

python -m scripts.import_pilot160 --validate \
  --public /path/to/participant \
  --private /path/to/organizer
```

참가자 폴더에는 실제 음성 150개, 개발 정답, 개발/평가 입력 JSON, Copy draft 제출 CSV·점수,
데이터 카드, 라이선스 고지, 파일 해시 잠금이 있습니다. 평가 입력은 `id,audio,draft`만 가집니다.

운영자 폴더에는 평가 정답, 원천 대응표, 변환·제외 구간 기록, 청취 검수표, 예비 음성 10개,
첨부 원천 주석이 있습니다. **이 폴더와 운영자 ZIP은 공개 GitHub에 올리지 않습니다.**
참가자 폴더 안에 운영자 폴더를 두지 않습니다.

채점을 실행할 수는 없으며, 이 변환 자체가 외부 채점 서버를 배포하지는 않습니다.

현재 상태는 **청취 미검수 파일럿**입니다. 기존 FLEURS v2를 대체하거나 그 점수와 합산하지 않습니다.
원천 전사·누락 간투사·이름 식별 가능성·오답 발음 구별 가능성을 독립 청취로 확인해야 합니다.
