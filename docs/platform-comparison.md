# Kaggle·Codabench와 비교한 Trust Your Ears

확인일: 2026-10-23. 범용 플랫폼의 전체 기능 평가가 아니라, 이 수업 챌린지의 참여 이유와 현재 구현 범위를 비교합니다.

**제안하는 대회:** 한국어 음성과 실제 ASR 초안을 받아, 틀린 부분을 고치고 이미 맞은 부분은 지키는 전사 교정 챌린지.

Kaggle는 자동 채점·리더보드·맞춤 Python 지표·공개/비공개 순위를 제공합니다. 따라서 ‘자체 지표로 자동 채점한다’는 사실만으로 차별성을 주장하지 않습니다. [Kaggle 공식 대회 구성 안내](https://www.kaggle.com/docs/competitions-setup)

Codabench도 여러 점수 열, 주 순위 지표, 최고 제출 선택과 숨겨진 리더보드를 지원합니다. 여러 지표와 팀별 최고 기록 역시 우리만의 플랫폼 기능이 아닙니다. [Codabench 공식 리더보드 안내](https://docs.codabench.org/v1.27/Organizers/Benchmark_Creation/Leaderboard-Functionality/)

## 참가자가 경험하는 차이

| 항목 | 범용 서비스에서의 구성 | Trust Your Ears가 제공하는 구체적 구성 |
|---|---|---|
| 과제 | 주최자가 데이터·입출력·채점법을 정의 | 한국어 음성 + 실제 ASR 초안 → 교정한 전체 전사문. 정답 초안도 포함해 수정과 보존을 함께 요구 |
| 첫 체험 | 대회 안내를 읽고 예측 파일을 제출 | 두 녹음을 듣고 수정 여부 선택 → 실제 모델 출력 비교 → 로그인 없이 Copy 채점 |
| 결과 해석 | 주최자가 평가 피드백 구성 | Micro CER로 순위 비교, 오류 슬롯 복원률·정상 문자 훼손률을 결과 상단에 표시. 나머지 지표·조건별 결과도 확인 가능 |
| 첫 모델 | 주최자가 코드·노트북 제공 가능 | CPU 학습·평가 노트북, Copy·Whisper 성능 목표, 세 Qwen 입력 방식의 실행 예제 제공 |
| 추가 도전 | 주최자가 보조 과제 구성 가능 | 같은 409개 원본의 원음·잡음·패킷 손실 조건을 비교하는 공개 개발용 보조 트랙 |

이 구성은 다른 플랫폼에서도 구현할 수 있습니다. 차별점은 독점 기능이나 세계 최초라는 주장이 아니라, **‘언제 고치고 언제 그대로 둘까?’라는 한 가지 도전을 데이터·체험·피드백으로 일관되게 제시하는 것**입니다. 낭독 음성을 사용하므로 실제 대화 전반의 성능을 입증하는 대회로 설명하지 않습니다.

구현 확인: [참가 이유와 두 음성 체험](https://jhparktime.github.io/TURST-YOUR-EARS/#why), [웹 채점](https://jhparktime.github.io/TURST-YOUR-EARS/#submit), [시작 노트북](https://jhparktime.github.io/TURST-YOUR-EARS/#start), [음질 보조 트랙](https://jhparktime.github.io/TURST-YOUR-EARS/stress.html).

## 현재 운영 방식과 한계

| 항목 | 현재 구현 |
|---|---|
| 채점 | Public Eval 409개를 브라우저에서 채점. Python·브라우저 평가 코드를 공개하며 공개 리더보드 등록 CSV는 GitHub Actions에서 다시 채점 |
| 보관 | 개인 최근 20건은 해당 브라우저에 저장. 리더보드 제출은 GitHub에 누적하고 팀별 최고 기록을 표시 |
| 등록 흐름 | 묶음 생성·복사 후 GitHub 양식에 붙여 넣기. GitHub 로그인과 비동기 처리 필요. 로컬 채점만 하면 CSV를 업로드하지 않음 |
| 공개 범위 | 공개 리더보드 등록 시 팀·계정·방법·코드 링크·예측 CSV 공개. 비공개 예측 제출 서비스로 설명하지 않음 |
| 공개 Eval | 개발·재현을 위해 정답을 배포한 개발용 순위. 최종 비공개 성능 검증과 구분 |
| Private Test | 정답은 운영자가 보관하고 별도 평가. 온라인 접수 API는 현재 연결하지 않음 |
| 검증의 의미 | 체크섬은 버전·내용 일치 확인용. 사전학습 유출 방지나 규칙 준수를 증명하지 않음 |

운영 세부 사항: [공개 리더보드 등록·제출 제한·보관 규칙](public-leaderboard.md), [참가 규칙](competition-rules.md), [평가 규격](real-asr-v2.md). 사이트의 진단 두 지표는 보조 설명이며, Micro CER 단일 순위 규칙을 바꾸지 않습니다.
