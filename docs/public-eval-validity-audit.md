# Public Eval 40개 타당성 감사

이 감사는 “문자열 오류가 실제 ASR 오류인지, 음성 단서가 필요한 교정 사례가 있는지”를 작게 확인하기 위한 사전 검증이다. 공식 데이터, 평가 규격, 웹 순위는 바꾸지 않는다. 독립 청취를 완료하기 전에는 검수 완료나 난도 검증으로 소개하지 않는다.

## 표본 고정

공개 Eval 409개에서 생성기 2종 × 기존 정규화 기준 clean/error 2종의 네 층으로 나누어 각각 10개씩 추출한다. seed는 `tye-eval-validity-audit-40-v1-20261022`이며 SHA-256 정렬의 앞 10개를 선택한다. 모델 예측·오류 크기·음성 길이를 보고 뽑지 않는다. 재생 순서는 별도 해시로 섞고 생성기와 층 이름은 검수자에게 숨긴다. 균등 층화 40개는 전체 Eval의 자연 분포와 다르므로 표본 비율과 CER를 전체 결과처럼 보고하지 않는다.

표본, 음성, 공개 입력·정답, 기존 다섯 예측의 해시를 기록한다. 기존 완료 측정의 공개 해시와 같아야 묶음을 생성할 수 있다. Private Test 파일은 열지 않는다. 출력 폴더가 이미 존재하면 덮어쓰지 않는다.

## 독립 청취

운영자는 `reviewer-only.zip`만 전달한다. `organizer` 폴더에는 정답·기존 모델 결과가 있으므로 검수자에게 전달하지 않는다. 검수자 묶음에는 원천 정답과 모델 출력이 아예 포함되지 않는다. 초안은 화면상 전사 확정 뒤 보여 주며, HTML 소스에는 포함되므로 의도적인 열람을 기술적으로 차단하는 도구는 아니다.

검수자는 이 표본 제작·정답 검토에 참여하지 않고 기존 정답·모델 결과를 미리 보지 않았음을 확인한다. 이는 자기 진술이며 자동 인증이 아니다. 먼저 음성만 듣고 전사를 확정한다. 숫자는 들린 발음을 한글로 쓰고, 어미를 보존하며 불명료 구간은 `[불명료]`로 남긴다. 이후 초안을 보고 실제 오류, 표기 차이, 둘 다, 올바른 초안, 판별 불가 중 하나를 선택한다. 음성이 필요하다고 판단한 경우 구체적인 단어와 청취 단서를 적는다.

음성 필요 여부는 검수자의 사후 판단이다. 동일인의 음성 청취 전후 성적을 비교한 무작위 실험이 아니므로 인과적 음성 효과를 입증했다고 쓰지 않는다. 한 사람의 독립 전사도 오류가 있을 수 있으며, 원천 정답과 다르다는 이유만으로 원천 오류를 확정하지 않는다.

## 자동 사전 점검

기존 예측을 전체 409개와 고정 40개에서 각각 재채점한다. 아라비아 숫자를 제한된 한글 수사로 바꾸면 문장 전체가 원천 정답과 같아지는 사례를 따로 표시한다. 이는 정답을 사용해 찾은 검토 후보로, “표기만 다른 오류”의 확정 개수나 모델의 개선 점수가 아니다. 예를 들어 `2주/이주`는 음성·문맥에 따라 의미가 다르다. 공식 정규화 규칙을 바꾸거나 숫자를 일괄 삭제하지 않는다.

## 검수 후 재채점

검수 JSON의 표본 해시, 독립성 자기 진술, 중복·알 수 없는 ID, 판단 항목을 검사한다. `[불명료]` 또는 판별 불가는 다섯 방법에서 공통 제외한다. 나머지 동일 문장에 대해 원천 정답 점수와 음성만 듣고 확정한 독립 전사 점수를 나란히 산출한다. 뒤늦게 본 초안에 맞춰 전사를 수정하지 않는다. 부분 검수도 개수·제외·미완료를 표시하며, 40개 완료로 간주하지 않는다.

허용 표기를 확정한 정식 정답 교체가 아니라 **단일 독립 전사에 대한 점수 민감도**다. 표기 불일치나 순위 변동이 크면 추가 판정이 필요한 결함을 찾은 것이다. 안정적이어도 이 소표본만으로 전체 타당성을 확정할 수 없다. 새로운 모델 실행이나 공식 Test 결과로 표본을 다시 고르지 않는다.

## 실행

저장소 루트에서 다음과 같이 실행한다. 모든 경로는 로컬 공개 자료와 기존 예측이다.

```sh
python -m scripts.audit_public_eval build \
  --public /path/to/tye-ko-asr-v2-public \
  --omni /path/to/asr-v2-baselines/omni \
  --comparison /path/to/asr-v2-baselines/comparison.json \
  --output /path/to/new-audit-directory

python -m scripts.audit_public_eval score \
  --audit /path/to/new-audit-directory \
  --reviews /path/to/tye-public-eval-40-human-review.json \
  --output /path/to/human-reference-sensitivity.json
```

웹이나 서버에 업로드할 필요가 없다. 생성한 검수 묶음을 여는 것과 실제 검수를 완료하는 것은 구분한다.
