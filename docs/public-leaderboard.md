# Public Eval 공동 리더보드

웹 채점 결과는 두 경로로 보관합니다.

- **개인 기록:** 최근 20건을 현재 브라우저에 저장합니다. 새로고침 후에도 남지만 다른 기기와 동기화하지 않습니다. 브라우저 데이터 삭제·비공개 모드·저장소 차단 시 보존되지 않을 수 있습니다. 전체 지표 JSON도 내려받을 수 있습니다.
- **공동 기록:** 참가자가 명시적으로 등록한 CSV를 GitHub Actions에서 Python 평가기로 다시 채점합니다. 결과는 `leaderboard-data` 브랜치의 `public-eval.json`에 누적하며 누구나 사이트에서 조회할 수 있습니다. 브라우저가 보내는 점수는 순위에 사용하지 않습니다.

## 참가 방법

1. 사이트의 **웹 채점**에서 Eval CSV 또는 Copy 예제를 채점합니다.
2. **공동 순위에 내 결과 등록하기**에 팀명, 모델·방법, 공개 코드 또는 재현 안내 HTTPS 링크를 입력합니다.
3. 공개 항목과 참가 규칙 준수를 확인하고 **등록 묶음 만들기 → 묶음 복사**를 누릅니다.
4. **GitHub 제출 양식 열기**로 이동해 로그인한 뒤 `Result package` 칸에 JSON 전체를 붙여 넣고 이슈를 제출합니다.
5. 자동 채점이 끝나면 사이트의 **공동 기록 새로고침**을 누릅니다. 정상·동일 파일·반려와 사유를 **참가자 제출 이력**에서 확인합니다. 처리·배포망 캐시 때문에 반영까지 수 분 걸릴 수 있습니다.

팀명·GitHub 계정·방법·코드 링크·예측 CSV가 공개됩니다. 로컬 채점만으로는 외부에 업로드하지 않습니다. 압축은 전송 형식이며 비밀 보호 수단이 아닙니다. 비공개 Test 자료나 키는 제출하지 않습니다.

## 순위와 이력

- 팀 대표 GitHub 계정 하나로 제출합니다. 최초 유효 등록의 팀명을 계정에 연결하고, 다른 계정이 같은 팀명을 사용하는 것을 거부합니다. 계정명과 함께 표시해 신원을 구분합니다. 계정 인증이 코드·모델 사용 규칙 준수까지 인증하는 것은 아니므로 운영자 검토는 별도입니다.
- 계정당 **하루 신규 유효 제출 5회, 00:00 KST 초기화**입니다. 동일 CSV는 기존 결과와 연결하며 신규 횟수를 쓰지 않습니다. 형식·버전·체크섬·ID 검증 실패도 유효 횟수에서 제외합니다.
- 팀별 가장 낮은 **반올림 전 Micro CER**를 베이스라인과 같은 표에 표시합니다. 동점은 공동 순위입니다. 가장 좋은 기록을 갱신하지 못한 제출도 전체 이력에 남습니다.
- 개인 브라우저 기록은 서버 검증 기록과 구분하며 새 CSV를 고르면 현재 비교 행만 초기화합니다. 기존 개인 이력은 남습니다.
- 공동 등록은 **Public Eval 409개** 전용입니다. Private Test 1,750개 접수와 순위는 별개이며 현재 온라인 접수를 열지 않았습니다.
- 웹 채점 CSV 한도는 2 MiB입니다. GitHub 양식에 넣는 압축 JSON 묶음은 60,000자 이하입니다. 길이 제한을 넘으면 사이트가 등록 묶음 생성을 거부합니다.

## 저장·운영 구조

`public-results-v2.js`가 브라우저 이력과 gzip+base64 묶음을 만듭니다. 묶음에는 고정 Eval manifest SHA-256과 원본 CSV SHA-256을 포함합니다.
`public_leaderboard.py`는 GitHub가 제공한 제출 계정·시각을 사용해 묶음을 검증하고 CSV를 다시 채점합니다. 참가자 코드 실행, 외부 코드 다운로드, 참가자가 제공한 점수 사용은 없습니다.
공동 기록은 Git 커밋 이력으로 보관합니다. 이슈 수정이나 동일 작업 재실행이 기존 처리 결과를 덮어쓰지 않으며, 새 결과는 새 이슈로 제출합니다. 오류 수정·결과 제외가 필요한 경우 운영자가 근거와 변경 기록을 남깁니다.

작업은 순차 처리하며, 실행 시 아직 처리하지 않은 제출을 다시 확인합니다. 일시 실패한 경우 운영자가 Actions의 **Record public Eval submissions**를 다시 실행하면 누락된 제출을 재처리합니다. 등록 버튼을 누르지 않은 로컬 파일은 수집하지 않습니다.

별도 상시 서버 없이 GitHub Pages·공개 저장소·표준 GitHub 호스팅 러너를 이용합니다. [공개 저장소의 표준 러너 실행은 무료](https://docs.github.com/en/billing/concepts/product-billing/github-actions)이며, 유료 호스팅이나 대용량 러너를 사용하지 않습니다. 서비스 정책·이용 제한은 GitHub 기준을 따릅니다. 공동 데이터의 원본은 [public-eval.json](https://raw.githubusercontent.com/jhparktime/TURST-YOUR-EARS/leaderboard-data/public-eval.json)입니다.

수업 제출 HTML은 개인 채점기를 내장하고, 공동 기록은 같은 공개 원본을 온라인으로 조회합니다. 오프라인에서는 개인 채점·기록을 사용할 수 있지만 공동 기록 갱신은 인터넷 연결이 필요합니다.
