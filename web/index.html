Challenge overview

한국어 음성과 실제 음성인식기가 생성한 초안을 받아, 실제 발화에 맞게 교정한 전체 전사문을 제출합니다. 오류를 고치면서 원래 맞는 부분을 보존하는 것이 목표입니다.

공개 개발·재현을 위한 후보 데이터입니다. 자동 무결성 검사를 통과했으며, 청취 검수와 해석의 한계는 Dataset에 명시합니다.

Pipeline

  1. 원본 한국어 음성과 전사를 확보하고 화자·세션·동일 문장·음성의 분할 간 겹침을 검사합니다.
  2. Whisper와 Qwen이 음성만 듣고 초안을 만듭니다. 각 발화의 생성기는 정답이나 오류율을 보지 않는 고정 규칙으로 배정합니다.
  3. 참가 모델은 음성과 초안을 받아 교정한 전체 전사문을 출력합니다. 정답 전사는 모델 입력에 넣지 않습니다.
  4. 공개 Eval에서 개발한 뒤 비공개 Test로 평가합니다. 동일한 평가 코드로 문자 오류와 정상 부분 훼손을 함께 집계합니다.

Baseline & Method

초안 복사와 음성 재전사를 기준점으로 두고, 같은 Qwen 모델에 제공하는 입력을 바꿔 초안 결합의 효과를 비교합니다. 현재 베이스라인은 추가 학습 없이 실행합니다.

청취 검수·해석 범위: 독립 청취 검수는 0건입니다. 원천 정답 오류나 표기 차이가 남아 있을 수 있으며, 데이터 난도와 음성의 필요성이 확립된 벤치마크로 주장하지 않습니다. 아래 측정은 현재 후보 데이터와 고정된 베이스라인 설정에 대한 결과입니다.

참가자 ZIP에는 Train/Eval 음성·초안·정답과 음성 우선 청취 검수 도구가 포함됩니다. Test 정답과 검수표는 운영자 전용입니다. 숫자 표기, 원천 전사 오류와 불명료 발화는 별도 검수가 필요합니다.

Evaluation protocol

순위의 주 지표는 Micro CER입니다. 전체 치환·삭제·삽입 수를 전체 정답 문자 수로 나눕니다. 보조 Macro CER는 발화별 CER의 평균이며, v1의 조건별 평균과 정의가 다릅니다. v1과 v2의 점수는 비교하지 않습니다.

한국어는 NFC·소문자 변환 후 공백과 정해진 문장부호를 제외합니다. 숫자 사이 소수점은 유지합니다. ‘3시’와 ‘세 시’는 서로 다른 표기로 채점합니다. WER는 공백 기준 어절 오류율입니다.

  • 오류 슬롯 복원률·교정 정밀도·교정 F1: 원래 틀린 문자와 삽입 위치를 얼마나 정확히 수정했는지 확인합니다.
  • 정상 문자 훼손률·불필요 삽입률·Clean 변경률: 초안에서 맞던 부분을 얼마나 보존했는지 확인합니다.
  • 초안의 오류 유형과 생성기별 결과를 함께 공개합니다. 슬롯 지표는 결정적 문자 정렬에 의한 진단이며 음향적 정당성을 인증하지 않습니다.

Baseline measurements

Copy는 배포 초안 그대로입니다. Audio-only는 음성만 사용하고, Text-only와 Audio+draft는 새 실제 ASR 초안을 사용합니다. 아래 표는 운영자가 측정한 베이스라인 결과이며 참가자 공식 순위와 구분합니다.

초안을 만든 인식기와 같은 Audio-only 기준점은 해당 생성기 부분집합에서 Copy와 같습니다. 이를 독립적인 교정 성공으로 해석하면 안 됩니다. 아래에 생성기별 CER도 함께 표시합니다.
