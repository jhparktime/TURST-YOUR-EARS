01 / CHALLENGE

Hear the words.
Question the reference.

Context-Robust Speech Recognition: transcribe the audio faithfully, whether the reference helps or misleads.

The task

Input
An audio clip and a reference name list.
Output
The complete spoken transcript for each sample ID.
Target
Preserve helpful contextual gains while reducing context-induced errors.

Our research project

Verify Before You Correct. Generate a context-informed correction, compare it with the original transcript against the audio, then accept or reject the edit.

  1. Recognize speech without context.
  2. Propose a contextual correction.
  3. Check the changed words against the audio.
  4. Keep only supported changes.

A proposed method to investigate, not a demonstrated improvement.

A balanced evaluation

Helpful

Measure the benefit of relevant names.

Misleading

Measure resistance to plausible wrong names.

Irrelevant

Measure the ability to disregard unhelpful lists.

Planned acoustic conditions: clean and noisy. The official condition matrix will be frozen before the final evaluation. Toy sandbox conditions are for pipeline testing only.

How scores are calculated

PRIMARY METRIC · LOWER IS BETTER

Macro condition WER

Calculate word error rate across all reference words within each condition, then average the condition rates equally.

WER = (S + D + I) / N

Normalization v1

Unicode NFKC, case folding, punctuation replaced by spaces, then whitespace tokenization. Numbers are not expanded: “15” and “fifteen” differ. WER can exceed 100%.

Ranking & submission policy

Best macro WER per team. Exact ties use the earlier submission. Five accepted unique submissions per UTC day by default. Invalid files do not use the allowance; identical predictions reuse the existing score.

For a public challenge, pretraining and external-data rules must be frozen before launch. Public source transcripts may already be known to models; transformed public data does not establish an unseen test set. Final results should report this limitation.
