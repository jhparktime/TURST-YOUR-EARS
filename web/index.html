참가 규칙

공개 Eval은 횟수 제한 없이 채점할 수 있습니다. 공정한 비교를 위해 다음 규칙을 적용합니다.

  1. 팀: 1–2명으로 참가하며 한 사람은 한 팀에만 참여합니다. 비교 결과를 공유할 때 팀명과 사용 방법을 명시합니다.
  2. 학습: Train 정답으로 학습하고 Eval 정답은 개발·채점에 사용합니다. Eval/Test 정답을 추론 입력에 넣거나 ID별 정답 사전을 만드는 행위, 평가 문장을 수작업으로 고치는 행위는 허용하지 않습니다.
  3. 외부 자원: 공개 사전학습 모델과 외부 데이터를 사용할 수 있습니다. 모델 버전·라이선스·데이터 출처를 공개하고 Eval/Test 원천 발화 및 파생 자료는 추가 학습에서 제외합니다. 사전학습 포함 여부가 불명확하면 그 사실을 기재합니다.
  4. 제출: UTF-8 CSV, 헤더 id,prediction, Eval 409개 ID 각 1회, 최대 2 MiB입니다. 전체 교정 전사문만 넣고 설명은 넣지 않습니다. 쉼표·따옴표는 CSV 인용 규칙을 따릅니다.
  5. 순위: 반올림 전 Micro CER 오름차순입니다. 같은 값은 공동 순위(1, 2, 2, 4)를 부여합니다. 보조 지표를 임의 가중합하지 않으며 공개 Eval과 비공개 Test 순위는 분리합니다.
  6. 재현성: 공개 비교 결과에는 코드, 모델·파라미터, 학습 데이터, seed와 실행 환경을 기록합니다. 모든 평가 발화에 같은 추론 절차를 적용합니다.
  7. 운영: 웹 공개 채점 결과는 개인 비교용입니다. Test 온라인 접수 시 팀별 신규 유효 제출은 하루 5회(09:00 KST 초기화), 동일 파일 재제출은 이전 결과를 반환합니다. 규칙 변경과 데이터 수정은 버전 및 변경 내역으로 공지합니다.

Evaluation protocol

주 지표 Micro CER는 전체 치환·삭제·삽입 수를 전체 정답 문자 수로 나눈 값입니다. 낮을수록 좋습니다. Macro CER는 발화별 CER의 평균이며, WER와 함께 보조 지표로 제공합니다. 과거 v1 점수는 다른 규격이므로 같은 순위에 섞지 않습니다.

한국어는 NFC·소문자 변환 후 공백과 정해진 문장부호를 제외합니다. 숫자 사이 소수점은 유지합니다. ‘3시’와 ‘세 시’는 서로 다른 표기로 채점합니다. WER는 공백 기준 어절 오류율입니다.

  • 오류 슬롯 복원률·교정 정밀도·교정 F1: 원래 틀린 문자와 삽입 위치를 얼마나 정확히 수정했는지 확인합니다.
  • 정상 문자 훼손률·불필요 삽입률·Clean 변경률: 초안에서 맞던 부분을 얼마나 보존했는지 확인합니다.
  • 초안의 오류 유형과 생성기별 결과를 함께 공개합니다. 슬롯 지표는 결정적 문자 정렬에 의한 진단이며 음향적 정당성을 인증하지 않습니다.

Pipeline

  1. 원본 한국어 음성과 전사를 확보하고 화자·세션·동일 문장·음성의 분할 간 겹침을 검사합니다.
  2. Whisper와 Qwen이 음성만 듣고 초안을 만듭니다. 각 발화의 생성기는 정답이나 오류율을 보지 않는 고정 규칙으로 배정합니다.
  3. 참가 모델은 음성과 초안을 받아 교정한 전체 전사문을 출력합니다. 정답 전사는 모델 입력에 넣지 않습니다.
  4. 공개 Eval에서 개발한 뒤 비공개 Test로 평가합니다. 동일한 평가 코드로 문자 오류와 정상 부분 훼손을 함께 집계합니다.
Private Test 평가 방식

비공개 Test 1,750개·4시간은 운영자의 최종 비교 평가용입니다. 위 리더보드의 Test 값은 고정 베이스라인 측정치입니다. 참가자는 현재 공개 Eval과 웹 채점을 이용합니다. 온라인 Test 접수를 열 때에는 일정과 팀 키 발급 방법을 공지합니다.
