RESEARCH PROPOSAL

Verify Before You Correct

참고자료로 교정 후보를 만든 뒤, 바뀌는 이름을 음성과 다시 비교해 근거가 있는 수정만 반영하는 방법을 연구합니다.

  1. 문맥 없이 음성을 전사합니다.
  2. 참고자료로 교정 후보를 만듭니다.
  3. 원래 표현과 후보의 음향적 근거를 비교합니다.
  4. 검증된 교정만 반영합니다.

실험할 가설입니다. 성능 개선이나 독창성이 검증된 결과는 아직 없습니다.

한국어 평가 규격

아래는 현재 샌드박스에 구현된 규칙입니다. 공식 대회의 데이터 구성과 조건 비중은 파일럿 후 확정하여 별도로 공지합니다.

PRIMARY METRIC · ko-cer-v1

Macro CER ↓

공백을 제외한 문자 오류율입니다. 한글은 자모가 아닌 음절 단위로 셉니다. 조건 안에서는 오류·정답 문자 수를 합산하고, 조건별 비율을 동일 비중으로 평균합니다.

CER = (S + D + I) / N
메인 순위와 보조 진단 · 주석이 없는 지표는 N/A로 표시합니다.
지표 계산 대상 해석
Macro CER ↓ 모든 문맥 조건 메인 순위 · 전체 전사 정확도
핵심 개체 정확도 ↑ 주석된 이름의 출현 위치 허용 표기를 포함해 이름을 맞힌 비율
오답 문맥 수용률 ↓ 오답을 주입한 목표 위치 주입한 이름을 해당 위치에 출력한 비율
부분 오류 동시 정답률 ↑ 이름 주석이 있는 부분 오류 발화 해당 발화의 모든 목표 이름을 맞힌 비율
최악 조건 CER ↓ 조건별 CER의 최댓값 가장 취약한 조건의 성능

정규화는 어디까지 하나요?

NFC 유니코드 정규화, 영문 소문자화, 모든 공백 제거를 적용합니다. 쉼표·물음표·따옴표 등 지정한 문장부호와 문장 끝 마침표는 제외합니다. 숫자 사이의 소수점, 부호, 퍼센트 기호는 유지합니다. 조사·어미·숫자 값은 바꾸지 않습니다. CER은 100%를 넘을 수 있습니다.

3시와 세 시, AI와 에이아이는 같은 정답인가요?

메인 CER에서는 자동으로 같게 만들지 않습니다. 이름·숫자 구간에 사전 승인된 대체 표기가 주석되어 있으면 개체 정확도에서만 인정합니다. 예측 결과를 본 뒤 대체 표기를 추가하지 않습니다. 의역, 동의어, 비슷한 발음만으로 정답 처리하지 않습니다.

이름만 나열해도 개체 점수가 올라가나요?

출력 전체에서 이름을 검색하지 않습니다. 전사문을 최소 편집거리로 정렬한 후 주석된 위치를 평가합니다. 삽입 오류는 CER에도 반영됩니다. 동일 비용 정렬은 대각선·삭제·삽입 순으로 결정하며, 이름 오른쪽 경계의 삽입은 해당 이름에 포함합니다. 자세한 구현과 경계 사례는 공개 코드와 테스트를 따릅니다.

동점과 제출 횟수는 어떻게 처리하나요?

팀별 가장 낮은 Macro CER을 반올림 전 값으로 정렬합니다. 정확한 동점은 공동 순위입니다. 기본 제출 한도는 UTC 하루 5회이며 한국 시간 오전 9시에 초기화됩니다. 무효 파일은 차감하지 않고, 같은 예측을 다시 제출하면 기존 결과를 돌려줍니다. 서버에 표시되는 실제 한도를 확인하세요.

오답 문맥 수용률이 곧 문맥의 인과적 영향인가요?

아닙니다. 문맥 없이도 같은 오답이 나올 수 있습니다. 문맥 때문에 정답이 오답으로 바뀌었는지는 동일 모델의 No context 실행과 짝지어 따로 분석해야 합니다. 신뢰구간과 짝지은 변화 분석은 공식 연구 보고 단계에 계획되어 있으며 현재 채점 결과에 포함되지 않습니다.

공식 공개 전에 조건 구성, 외부 데이터·사전학습 규칙, 표기 기준을 확정합니다. 한국어 원천 데이터는 아직 선정되지 않았으며 사람의 독립 청취 검수와 화자·세션 분리가 필요합니다. 채점 코드 보기 ↗
