참가 규칙

공개 Eval은 횟수 제한 없이 채점할 수 있습니다. 공정한 비교를 위해 다음 규칙을 적용합니다.

  1. 팀: 1–2명으로 참가하며 한 사람은 한 팀에만 참여합니다. 비교 결과를 공유할 때 팀명과 사용 방법을 명시합니다.
  2. 학습: Train 정답으로 학습하고 Eval 정답은 개발·채점에 사용합니다. Eval/Test 정답을 추론 입력에 넣거나 ID별 정답 사전을 만드는 행위, 평가 문장을 수작업으로 고치는 행위는 허용하지 않습니다.
  3. 외부 자원: 공개 사전학습 모델과 외부 데이터를 사용할 수 있습니다. 모델 버전·라이선스·데이터 출처를 공개하고 Eval/Test 원천 발화 및 파생 자료는 추가 학습에서 제외합니다. 사전학습 포함 여부가 불명확하면 그 사실을 기재합니다.
  4. 제출: UTF-8 CSV, 헤더 id,prediction, Eval 409개 ID 각 1회, 최대 2 MiB입니다. 전체 교정 전사문만 넣고 설명은 넣지 않습니다. 쉼표·따옴표는 CSV 인용 규칙을 따릅니다.
  5. 순위: 반올림 전 Micro CER 오름차순입니다. 같은 값은 공동 순위(1, 2, 2, 4)를 부여합니다. 보조 지표를 임의 가중합하지 않으며 공개 Eval과 비공개 Test 순위는 분리합니다.
  6. 재현성: 공개 비교 결과에는 코드, 모델·파라미터, 학습 데이터, seed와 실행 환경을 기록합니다. 모든 평가 발화에 같은 추론 절차를 적용합니다.
  7. 운영: 개인 채점은 횟수 제한이 없고 최근 20개 결과를 브라우저에 저장합니다. 공동 Eval은 팀 대표 GitHub 계정당 하루 신규 유효 제출 5회(00:00 KST 초기화)이며 동일 CSV는 제외합니다. 팀별 최고 기록과 모든 처리 이력을 공개합니다.

OpenSLR SLR40 · 사용한 원천 버전

  1. 공개 원천 확보: Zeroth Korean의 고정 버전에서 음성과 배포 전사를 확보했습니다. 16 kHz·모노 PCM 샘플을 보존해 WAV로 내보내고 전사에는 NFC 정규화만 적용했습니다.
  2. 통합·분할: 기존 2,079개와 추가 2,002개를 합친 4,081개에서 Train/Eval/Test 2,631개를 구성했습니다. 분할 간 화자·세션·동일/유사 문장·음성 겹침을 검사했고, 나머지 1,450개는 운영자 예비 풀로 보관했습니다.
  3. 실제 초안 생성: 고정한 Whisper와 Qwen에 음성만 입력했습니다. 발화 ID의 해시 순서로 생성기를 번갈아 배정하며, 배정에는 정답·오류율을 사용하지 않았습니다. Eval은 Whisper 205개·Qwen 204개이며, 이미 맞은 초안 131개도 그대로 포함합니다.
  4. 자동 검사: 활성 녹음 2,631개의 복호화·길이·체크섬, 원천 전사 보존, 실제 추론 출력과 초안의 일치를 확인했습니다. Copy·정답 제출의 기본 동작과 Python·브라우저 채점 결과도 대조했습니다.
  5. 배포: Train/Eval 음성·초안·정답·출처·체크섬을 참가자에게 제공합니다. Test 정답·원천 대응표·예비 풀은 운영자가 보관합니다. 평가 5시간은 Eval 1시간 + Test 4시간이며 Train 약 1시간 13분은 별도입니다.
이전 버전에서 무엇이 달라졌나요?

v1의 합성 단어 치환 초안을 v2에서 실제 ASR 출력으로 교체했고, 녹음·정답·분할은 유지했습니다. 기존 Eval/Test 풀은 합성 치환 후보가 있는 문장을 선정한 이력이 있습니다. v2 배정에서 오류율을 보지 않은 것과는 별개이며, 수집·구축 기록에 선정 이력과 검증 범위를 남겼습니다.

수집·통합·분할·초안 생성 기록 전체 보기 · 수량·시간·모델 버전 메타데이터

정답 기준: 운영자가 확인한 Zeroth Korean 배포 전사를 기준 전사로 사용합니다. 음성을 새로 녹음하거나 전사문을 임의로 바꾸지 않았습니다. 숫자 표기·띄어쓰기 등의 차이는 아래 정규화 규칙으로 처리합니다. 기준 전사에 대한 이의는 발화 ID와 근거를 GitHub Issues로 알려주세요. 수정 시 데이터 버전과 변경 내역을 공개합니다.

참가자 ZIP에는 Train/Eval 음성·초안·정답과 출처·체크섬 정보가 들어 있습니다. Test 정답과 개별 예측은 운영자 전용입니다. 평가 데이터는 한국어 낭독 음성이며, 대화나 모든 도메인의 성능을 대표하지 않습니다.

Evaluation protocol

주 지표 Micro CER는 전체 치환·삭제·삽입 수를 전체 정답 문자 수로 나눈 값입니다. 낮을수록 좋습니다. Macro CER는 발화별 CER의 평균이며, WER와 함께 보조 지표로 제공합니다. 과거 v1 점수는 다른 규격이므로 같은 순위에 섞지 않습니다.

한국어는 NFC·소문자 변환 후 공백과 정해진 문장부호를 제외합니다. 숫자 사이 소수점은 유지합니다. ‘3시’와 ‘세 시’는 서로 다른 표기로 채점합니다. WER는 공백 기준 어절 오류율입니다.

  • 오류 슬롯 복원률·교정 정밀도·교정 F1: 원래 틀린 문자와 삽입 위치를 얼마나 정확히 수정했는지 확인합니다.
  • 정상 문자 훼손률·불필요 삽입률·Clean 변경률: 초안에서 맞던 부분을 얼마나 보존했는지 확인합니다.
  • 초안의 오류 유형과 생성기별 결과를 함께 공개합니다. 슬롯 지표는 결정적 문자 정렬에 의한 진단이며 음향적 정당성을 인증하지 않습니다.

실행·학습 조건과 재현 방법

사전학습 모델을 추가 학습 없이 실행하고, 정답을 추론 입력에 넣지 않았습니다. 예측 CSV를 만든 뒤 별도 평가기로 채점합니다. 모델·입력·출력 해시를 기록하고, 빈 출력이나 길이 제한 출력도 그대로 평가합니다.

학습 노트북의 CPU 어절 치환 모델은 Train으로 학습하는 입문 예제이며, 위 다섯 측정 행과 별도입니다.

Pipeline

  1. 원본 한국어 음성과 전사를 확보하고 화자·세션·동일 문장·음성의 분할 간 겹침을 검사합니다.
  2. Whisper와 Qwen이 음성만 듣고 초안을 만듭니다. 각 발화의 생성기는 정답이나 오류율을 보지 않는 고정 규칙으로 배정합니다.
  3. 참가 모델은 음성과 초안을 받아 교정한 전체 전사문을 출력합니다. 정답 전사는 모델 입력에 넣지 않습니다.
  4. 공개 Eval에서 개발한 뒤 비공개 Test로 평가합니다. 동일한 평가 코드로 문자 오류와 정상 부분 훼손을 함께 집계합니다.
Private Test 평가 방식

비공개 Test 1,750개·4시간은 운영자의 최종 비교 평가용입니다. 위 리더보드의 Test 값은 고정 베이스라인 측정치입니다. 참가자는 현재 공개 Eval과 웹 채점을 이용합니다. 온라인 Test 접수를 열 때에는 일정과 팀 키 발급 방법을 공지합니다.
