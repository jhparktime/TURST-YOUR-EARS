RESEARCH PROPOSAL

Verify Before You Correct

초안과 독립적으로 얻은 음성 전사를 비교하고, 실제 발화의 근거가 충분한 수정만 반영하는 선택적 교정을 연구합니다.

  1. 초안을 보지 않고 음성을 전사합니다.
  2. 초안과 음성 전사가 다른 구간을 찾습니다.
  3. 차이가 나는 표현의 음향적 근거를 확인합니다.
  4. 개발셋에서 정한 기준에 따라 수정하거나 유지합니다.

제안 방법입니다. 음향 검증 모듈과 효과 검증은 후속 실험이며, 현재 베이스라인 구현과 구분합니다.

데이터 담당자 인계 규격

  1. 이용 조건을 확인한 음성·전사에서 발화를 선택합니다.
  2. 음성을 독립적으로 듣고 정답 전사를 검수합니다.
  3. 화자·세션 기준으로 개발·평가를 나눈 뒤 초안을 만듭니다.
  4. 정답은 유지하고, 치환 위치와 바꾼 표현을 기록합니다.
  5. 공개 입력과 비공개 정답을 분리해 전달합니다.

발화를 새로 녹음하거나 모든 문장을 직접 작성할 필요는 없습니다. 규모는 파일럿 난도와 검수 가능량을 보고 확정합니다.

공개 평가 입력에는 원본 음성당 초안 하나만 제공합니다. 동일 음성의 무오류·오류 변형을 함께 공개하면 서로 대조해 정답을 유추할 수 있습니다. 공개 코퍼스 재사용에 따른 원문 검색·사전학습 오염 가능성은 별도로 기록합니다.

Macro CER ↓

한글 음절 단위 문자 오류율입니다. 각 조건 안에서 오류 수와 정답 문자 수를 합산한 CER을 구하고, Clean·Single·Multiple을 각각 1/3 비중으로 평균합니다. 무오류 초안도 메인 순위에 포함됩니다.

CER = 100 × (S + D + I) / N
순위는 Macro CER · 나머지 지표는 교정 행동을 설명합니다.
지표 정의 좋은 방향
Macro CER 세 조건 CER의 동일 비중 평균 낮을수록
초안 대비 개선폭 초안 Macro CER − 출력 Macro CER, %p 높을수록 · 음수는 악화
오류 구간 복원률 주입 구간 전체를 정답으로 복원한 수 / 주입 구간 수 높을수록
정상 구간 훼손률 주입 구간 밖에서 훼손된 정답 문자 수 / 해당 문자 수 낮을수록
무오류 초안 변경률 정규화 후 출력이 달라진 Clean 발화 수 / Clean 발화 수 낮을수록

보조 지표는 해당 구간·문자·발화 수를 전체 조건에서 합산합니다. 분모가 0이면 N/A입니다. 최악 조건 CER, Micro CER, 띄어쓰기에 민감한 어절 WER도 제공합니다.

한국어 표기는 어디까지 정규화하나요?

NFC 정규화, 영문 소문자화, 공백 제거를 적용합니다. 지정된 문장부호와 숫자 사이가 아닌 마침표를 제외합니다. 소수점·부호·퍼센트 기호, 조사와 어미는 유지합니다. 숫자 읽기·동의어·발음 유사성을 자동으로 정답 처리하지 않습니다. 3시와 세 시, AI와 에이아이는 다르게 채점하므로 정답 표기 규칙을 데이터 공개 전에 확정해야 합니다. 오류율은 100%를 넘을 수 있습니다.

교정 위치는 어떻게 비교하나요?

정답과 출력을 최소 편집거리로 정렬합니다. 주입 구간의 정렬된 출력 전체가 정답과 같아야 복원으로 셉니다. 동일 비용이면 대각선·삭제·삽입 순으로 결정합니다. 삽입은 왼쪽 문자에 붙이고 문장 맨 앞 삽입은 첫 문자에 붙입니다. 데이터를 등록할 때 정답→초안 정렬이 치환 주석과 일치하는지도 확인합니다. 반복 표현이나 출력의 경계 삽입에서는 정렬 선택의 영향을 받는 진단값입니다. 최종 전사의 오류는 CER로 함께 확인합니다.

정상 구간 훼손률의 분모는 무엇인가요?

주입 구간 밖의 정답 문자 수입니다. 각 문자에 대응하는 출력이 그 문자와 다르면 훼손으로 셉니다. 치환·삭제와 해당 위치에 붙는 삽입을 포함합니다. 주입 구간 안의 원래 같던 글자는 이 분모에서 제외합니다. 주입 구간은 단어 또는 의미 있는 표현 단위로 일관되게 지정해야 합니다.

점수가 좋으면 음성을 잘 활용했다는 뜻인가요?

점수만으로는 알 수 없습니다. 초안만 보는 모델도 문법이나 상식으로 오답을 고칠 수 있습니다. 같은 모델의 Text only와 Audio + draft를 비교하고, 실제 ASR 초안으로 만든 별도 검증셋에서 재확인할 계획입니다. 음성 청취 검수와 실제 모델 실험은 코드 테스트로 대체하지 않습니다.

동점과 제출 횟수는 어떻게 처리하나요?

팀별 최저 Macro CER을 반올림 전 값으로 정렬하며 정확한 동점은 공동 순위입니다. 기본 한도는 UTC 하루 5회이며 한국 시간 오전 9시에 초기화됩니다. 무효 파일은 차감하지 않습니다. 같은 예측은 기존 결과를 반환합니다. 실제 한도는 서버 표시를 따릅니다.
