Challenge overview

한국어 음성과 실제 음성인식기가 생성한 초안을 받아, 실제 발화에 맞게 교정한 전체 전사문을 제출합니다. 오류를 고치면서 원래 맞는 부분을 보존하는 것이 목표입니다.

이 페이지는 v2 후보 버전입니다. 자동 무결성 검사는 완료했지만 독립 청취 검수는 아직입니다. 데이터 난도나 음성의 필요성을 검증한 완성 벤치마크로 소개하지 않습니다.

연구 질문: 음성을 근거로 수정할 부분을 선택하면, 실제 한국어 ASR 오류를 줄이면서 불필요한 교정을 억제할 수 있을까요?

데이터 생성·평가·검수 규격 · 베이스라인·재현 코드

Dataset

원본 녹음과 전사를 유지하고 Whisper large-v3-turbo와 Qwen2.5-Omni-3B의 실제 음성 단독 출력을 초안으로 사용합니다. 생성기를 고정 규칙으로 절반씩 배정하며, 인식 오류가 많은 녹음만 골라 넣지 않습니다.

Evaluation protocol

순위의 주 지표는 Micro CER입니다. 전체 치환·삭제·삽입 수를 전체 정답 문자 수로 나눕니다. 보조 Macro CER는 발화별 CER의 평균이며, v1의 조건별 평균과 정의가 다릅니다. v1과 v2의 점수는 비교하지 않습니다.

한국어는 NFC·소문자 변환 후 공백과 정해진 문장부호를 제외합니다. 숫자 사이 소수점은 유지합니다. ‘3시’와 ‘세 시’는 서로 다른 표기로 채점합니다. WER는 공백 기준 어절 오류율입니다.

  • 오류 슬롯 복원률·교정 정밀도·교정 F1: 원래 틀린 문자와 삽입 위치를 얼마나 정확히 수정했는지 확인합니다.
  • 정상 문자 훼손률·불필요 삽입률·Clean 변경률: 초안에서 맞던 부분을 얼마나 보존했는지 확인합니다.
  • 초안의 오류 유형과 생성기별 결과를 함께 공개합니다. 슬롯 지표는 결정적 문자 정렬에 의한 진단이며 음향적 정당성을 인증하지 않습니다.

Baseline measurements

Copy는 배포 초안 그대로입니다. Audio-only는 음성만 사용하고, Text-only와 Audio+draft는 새 실제 ASR 초안을 사용합니다. 미완료 실험에는 점수를 표시하지 않습니다.

초안을 만든 인식기와 같은 Audio-only 기준점은 해당 생성기 부분집합에서 Copy와 같습니다. 이를 독립적인 교정 성공으로 해석하면 안 됩니다. 아래에 생성기별 CER도 함께 표시합니다.
